The wine tree is derived from Wine and remains governed by the license files
inside that tree, principally LGPL-2.1-or-later. Preserve its copyright notices
and corresponding-source obligations when distributing binaries.

Juice-original files in app, launcher, scripts, toolchain, config, packaging,
docs, and the relevant parts of legacy are currently copyright the Juice
project owner with all rights reserved. The owner must choose and add an
explicit open-source license before advertising the project as open source.
Merely publishing the source on GitHub does not grant reuse rights.
